## Using Mochi in your own fork

Forks may use the code under MIT, and may ship the app with Mochi's artwork **unchanged and only as part of this project** (for example, when contributing back or running it for evaluation). To publish your own derivative app, replace the Mochi artwork with your own companion. Companions are data (`assets/pets/<name>/manifest.json`), so no code changes are needed; see `assets/pets/README.md`.
