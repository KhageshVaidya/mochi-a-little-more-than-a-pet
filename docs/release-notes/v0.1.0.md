# Mochi v0.1.0 — first public demonstration release

**Mochi — A Little More Than a Pet.** A little companion that lives on your desktop, gets to know you, plays with you, helps you reflect, and quietly brings people together. Built for the NASA Space Apps Challenge 2026.

> **Demonstration software.** Not a medical device; it does not diagnose. All astronaut health data is **synthetic** (five fictional crew members). Not affiliated with or endorsed by NASA.

## What's included

- **Mochi**, the desktop companion: click to chat, drag anywhere, menu-bar/tray controls.
- **Local AI** through Ollama with Qwen3 4B, set up by a first-run guide (asks before downloading about 2.5 GB). Any other Ollama model can be configured. Without a model, Mochi runs in a labelled **simple mode**.
- **Private journal and confirmed memories**, never sent to the model.
- **Dr G Zero**: the deterministic SCND engine (YES / NO / INSUFFICIENT DATA) with explanations, physical and mental wellbeing monitoring on synthetic data, long-term trends, and an offline, cited NASA Human Research Program risk registry.
- **Gamification**: Solar System exploration, habitat, mini-games, crew missions. Rest is never punished.
- **Crew features** (Fable precursor): voluntary statuses, activity invitations and crew puzzles, shown as crew totals.

## Known limitations

- **Unsigned installers.** macOS needs *System Settings → Privacy & Security → Open Anyway*; Windows SmartScreen needs *More info → Run anyway*.
- **Windows** has passed automated CI tests only; it has not been tested on a real Windows PC.
- **Ollama is a separate install**, and the model download (about 2.5 GB; about 3.2 GB of memory while chatting) needs a network connection once. No model is bundled.
- **Fable** coordination between separate computers is not implemented; crew activities run on one computer with simulated crewmates.
- **Synthetic data only.** No real sensors are connected. SCND thresholds are engineering defaults evaluated on synthetic cohorts, not clinically validated.
- **Placeholder artwork**: the dog, cat and alien companions are original placeholder designs, to be redrawn.
- The fallback model (`qwen3:4b`) is much slower than the default and not recommended for chat.
- A short goodbye phrase can sometimes end a conversation early (for example, a message containing "later").
- The app's data folder keeps its pre-rename name (`@orbital/desktop`).
